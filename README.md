##  About the Project

The **CA Portfolio Website** is a personal portfolio website designed and developed for my friend, a CA Final student currently pursuing her articleship at EY.

The goal of this project was to create a dedicated digital space where she could showcase her professional journey, skills, experiences, and personality through a modern and engaging web experience.

Rather than building a conventional resume-style website, I wanted to create a portfolio that presents professional information in a visually appealing and structured manner while making it easy for visitors to explore different sections and connect with her.

This project also gave me an opportunity to apply my frontend development skills, work with component-based architecture, explore UI/UX design, and use modern development tools to turn an idea into a live website.

##  Project Structure

The project follows a component-based structure to keep the code organized and easier to maintain.

```text
CA_Portfolio_Website/
│
├── public/                 # Public assets
│
├── src/
│   ├── Components/
│   │   ├── MainPage        # Main landing section
│   │   ├── Navbar          # Navigation component
│   │   ├── About           # About section
│   │   ├── Journey         # Professional journey
│   │   ├── Reels           # Visual/social content section
│   │   ├── Skills          # Skills section
│   │   └── Connect         # Contact/connect section
│   │
│   ├── App.jsx             # Main application component
│   ├── main.jsx            # React entry point
│   └── index.css           # Global styles
│
├── index.html              # HTML entry point
├── package.json            # Dependencies and scripts
├── vite.config.js          # Vite configuration
├── eslint.config.js        # ESLint configuration
└── README.md
```
